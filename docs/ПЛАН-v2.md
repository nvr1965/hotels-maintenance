# Гостиничное приложение: версия 2 (свой сервер, PostgreSQL, любые языки)

Решение Nick от 12.10.2026: отдельный сервер Ubuntu (сейчас виртуальный, потом выделенный), PostgreSQL, проект на GitHub, доступ снаружи через туннель. Главное отличие от Ramada: языки не зашиты в код.

## Сервер

Как в Allservice (`server/setup_server.sh`): Ubuntu 24.04, nginx, php-fpm 8.3, PostgreSQL 16, доступ снаружи через Cloudflare Tunnel (`cloudflared`), без открытых портов. Один скрипт настройки с нуля и `deploy.sh` для выкладки ветки.

## Языки

Устроено как уже сделано в Allservice, с тем же переводчиком (`translate.php`: MyMemory бесплатно, Google по ключу); добавляется Gemini, ключ уже есть.

- **Таблица `languages`**: код, название, название на самом языке, справа налево, включён, порядок. Новый язык добавляется строкой из админки.
- **Тексты интерфейса**: английский — основа, в файле в репозитории; остальные языки — в таблице `ui_translations`. При добавлении языка все тексты сразу переводятся автоматически, любой перевод можно поправить руками.
- **Справочники и названия** (объекты, обход номера, регламенты, заголовки отеля): вместо колонок `_ru/_en/_he/_ar` поле `jsonb` вида `{"ru": "...", "en": "..."}`. Пустые языки заполняются автопереводом при сохранении и при добавлении языка.
- **Перевод на лету**: то, что пишут люди (описание заявки, комментарии), хранится на языке автора и показывается каждому на его языке. Переводы кешируются в таблице, повторно не переводятся. Рядом кнопка «оригинал».
- **Языки отеля**: у каждого отеля свой набор из включённых языков системы.

## Что переносится из hotelapp (этапы 1–3)

Модель «сеть → отели → объекты», роли по отелям, брендинг из настроек, вкладка «Сеть и отели», перенос данных Ramada. Меняется слой базы (mysqli → PDO pgsql, запросы под PostgreSQL) и хранение текстов на языках. Интерфейс (React) остаётся, тексты из словарей в коде уходят в `ui_translations`.

## Этапы

1. Репозиторий, схема PostgreSQL с языками, скрипт настройки сервера, перенос Ramada (MariaDB → PostgreSQL).
2. Сервер API на PDO, перевод на лету.
3. Интерфейс: тексты из базы, страница «Языки», выбор любого языка.
4. Сервер Nick, туннель, проверка на данных Ramada.

## Состояние

- Этап 1 готов: схема `db/pg/01_schema.sql`, перенос `tools/migrate_ramada.php` (проверен на копии базы Ramada).
- Этап 2 готов: весь API на PDO и PostgreSQL, проверен на перенесённых данных. Написанное людьми (заявки, заметки, комментарии) показывается каждому на его языке, оригинал отдаётся рядом (`*_orig`). Справочники и заголовок отеля дописываются на все языки отеля при сохранении; при добавлении языка отелю справочники переводятся сразу после ответа. Выгрузки Excel работают на любом языке (на ru/en/he/ar — готовые тексты, на остальных — автоперевод английских).
- Для проверки без интернета в `config.local.php` можно поставить `'translate_provider' => 'fake'` (перевод вида «[de] текст»).
