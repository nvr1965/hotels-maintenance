# Hotels Maintenance

Техническое обслуживание гостиниц и сетей гостиниц: срочные заявки, плановые обходы номеров,
регламентные работы, счётчики с распознаванием по фото, отчёты, уведомления на телефон.
Выросло из приложения отеля Ramada Olivié Nazareth.

- Сеть → отели → объекты. Роли в каждом отеле свои: Исполнитель, Менеджер, Руководитель, администратор отеля;
  в сети — администратор и наблюдатель.
- Название, цвета, логотип, языки, часовой пояс — настройки отеля.
- Языки не зашиты в код: новый язык добавляется в админке, интерфейс и справочники переводятся автоматически,
  заявки показываются каждому на его языке (перевод на лету).

## Стек

- PostgreSQL 16, PHP 8.3 (PDO), nginx + php-fpm
- React 19 + Vite (сборка в `react/`), PWA, Web Push
- Сервер: Ubuntu 24.04, доступ снаружи через Cloudflare Tunnel

## Структура

```
backend/api/      API (JSON)
backend/core/     общее: вход, отели и роли, переводы, push, распознавание счётчиков
db/pg/            схема PostgreSQL
frontend/app/     исходники интерфейса (React)
react/            готовая сборка интерфейса
brand/            логотипы и значки отелей
tools/            перенос данных Ramada и прочие скрипты
docs/             план и инструкции
```

## Правила

- В `main` напрямую не пишем: ветка → pull request → проверка → merge.
- Пароли и ключи в git не попадают: `config.local.php`, `secrets.php`, `push_keys.php` только на сервере.
- Все тексты интерфейса через переводы, никаких надписей прямо в коде.
